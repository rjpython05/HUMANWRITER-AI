2. Configure Environment
   ──────────────────────
   • Copy .env.example to .env
   • Set DATABASE_URL
   • Set JWT_SECRET
   • Set AI_ENGINE_URL
   • Set CORS_ORIGIN

3. Database Setup
   ──────────────
   cd /home/user/HUMANWRITER-AI/webapp
   npx prisma generate
   npx prisma migrate deploy

4. Start Services
   ──────────────
   • Backend API:  cd backend-api && npm run dev
   • AI Engine:    cd ai-engine && uvicorn src.main:app --reload
   • Frontend:     cd webapp && npm run dev

5. Verify Deployment
   ─────────────────
   • Run: bash scripts/verify-system.sh
   • Test API endpoints
   • Check logs for errors
